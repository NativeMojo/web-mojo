DetailView migration

ApiKeyView extends DetailView — same shell as Group / User / Member. Header carries the ✕ close (fixes “no close button”), the ⋮ menu (Edit name · Delete — Activate/Deactivate moves to the header switch), and the Active toggle autosaving is_active. No footer buttons: buttons: [] becomes correct only with this migration (never on the current hand-rolled view).

Permissions = Member parity

One autosaving FormView over the live Member.PERMISSION_TABSET — flipping a switch saves {"permissions.<name>": bool} (dotted key, flat), identical to MemberView. App-registered Member permissions appear as extra tabs automatically. Permissions outside the catalog are never shown and never touched.
